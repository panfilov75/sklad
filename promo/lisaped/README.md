# Лисапед — рекламный ролик

**`lisaped_promo_1080x1920.mp4`** — вертикальный ролик 1080×1920, 28 с, 30 fps, H.264 + AAC (громкость −14 LUFS).
Подходит для VK Клипов, историй, Telegram, постов в городских пабликах. `lisaped_cover.jpg` — обложка.

## Как пересобрать

Править текст озвучки: `src/script.json`; анимацию: `src/video.html` (откройте в браузере, `render(t)` в консоли); звук: `tools/audio.py`.

```bash
PIPER_MODEL=/путь/к/ru-irinia-medium.onnx tools/build.sh
```

- `tools/cutouts.py` — вырезка элементов из исходных макетов (`assets/src` → `assets/cut`), нужен `rembg`.
- `tools/logo_key.py` — белая надпись «Лисапед» из логотипа; иконка перерисована в вектор: `src/logo.svg`.
- `tools/voice.py` — озвучка нейросетевым голосом Piper (ru, Irina).
- `tools/audio.py` — синтез музыки (120 BPM), эффектов и сведение с голосом.
- `tools/render.js` — покадровый рендер HTML через Playwright → ffmpeg.
